`@konfig.ts/env` lets you declare a pod's environment once and use it from both sides of the wire. The same `Environment.define` value drives the Deployment env block (through `Environment.bind` in `@konfig.ts/k8s`) and the runtime decode (`Environment.runtime`, an Effect `Config` over the whole tree). Rename `DATABASE_URL` in one place and the typechecker flags every consumer.

## Install

```bash
bun add @konfig.ts/env
```

## Usage

The API contract from the full-stack example. Secrets are `Secret.define` entries shared with the worker; literals may carry a `Config` schema for decoding.

<Snippet file="shared/env-contracts/src/bundles.ts" startAt="export const apiEnv" endBefore="// Strict subset of apiEnv" title="shared/env-contracts/src/bundles.ts" />

On the process side, `Environment.runtime(apiEnv)` yields a typed record (`config.http.port` is a `number`, `config.db.password` is `Redacted`). On the manifest side, `Environment.bind({ env: apiEnv, namespace, secrets: { db: { backend } } })` returns `envVars` and the backend's `manifests`.

## Surface

| Export | Purpose |
| --- | --- |
| `Secret.define` | A secret contract `{ name, namespace, env }`; bound to a backend at compose time |
| `Literal.define` | A constant `{ envName, value, schema?, serialize? }` baked into the manifest; `serialize` is required for non-primitive values |
| `Downward.define` | A downward-API field `{ envName, fieldPath }` |
| `Environment.define` | A nestable bundle of the above; the single source of truth |
| `runtime` | Decode an `Environment` from the process env into an `EnvironmentShape` |
| `environmentLayer` | Wrap the decoded shape as a `Layer` for a service |
| `SecretSource` | Plaintext sources for backends: `fromConfig({ keys, envName? })`, `literal({ data })`, `fromCommand({ keys, run })` |
| `EnvClaim`, `HasEnvClaims`, `EntryKind`, `EntryMarker` | Metadata types used to detect env-name collisions |
| `AnyEnvironment`, `EnvMember`, `MemberValue`, `EnvironmentShape`, `SecretEntry`, `LiteralEntry`, `DownwardEntry`, `ResolvedSecretValues` | Types for generic helpers over contracts |

## Errors

- `EnvNameCollision`: two members of one bundle claim the same `envName`. `Environment.define` flags most collisions at compile time; the remaining cases throw this tagged error synchronously when the bundle is defined (module load), not inside an Effect.
- `SecretSourceError` (`{ source, key, cause }`): a `SecretSource` failed to resolve (`fromConfig` env var missing, `fromCommand` exit failure, `Sops.source` decrypt or extract failure).

<Aside type="note">
`Environment.bind` and `Environment.runtime` are re-exported from `@konfig.ts/k8s`, so app code that only decodes config still imports from `@konfig.ts/k8s`. Import from `@konfig.ts/env` when writing the shared contract package.
</Aside>

## Requirements

- `effect@4.0.0-rc.109` as an exact peer dependency (Effect 4, release candidate).
- Depends on `@konfig.ts/core`.
- Runtime: Bun recommended; Node >= 23.6 works; Node 22.6 to 23.5 with `--experimental-strip-types`; `tsx` works.
