`@konfig.ts/sealed-secrets` is the [Sealed Secrets](https://github.com/bitnami-labs/sealed-secrets) backend. At render time konfig resolves a `SecretSource` to plaintext (held only as `Redacted<string>` in memory), builds a plain `Secret`, pipes it to `kubeseal` over stdin, and emits the returned `SealedSecret` CR. Only the in-cluster controller can decrypt it, so the manifest is safe to commit.

## Install

```bash
bun add @konfig.ts/sealed-secrets
```

Needs the `kubeseal` CLI on the machine that runs `konfig build`, plus the controller's public certificate: `certPath`, else the `KUBESEAL_CERT` environment variable.

## Usage

Bind a contract from `@konfig.ts/env` to the backend and give it a source for the plaintext. `requiresSource: true` makes `source` a compile-time requirement.

```ts title="infra/modules/db.ts"
import { SecretSource } from "@konfig.ts/env"
import { Secret } from "@konfig.ts/k8s"
import { SealedSecrets } from "@konfig.ts/sealed-secrets"

const dbCreds = Secret.define({
  name: "db-creds",
  namespace: "prod",
  env: { url: "DATABASE_URL", password: "DATABASE_PASSWORD" }
})

const bound = Secret.bind({
  secret: dbCreds,
  backend: SealedSecrets.backend({ scope: "strict" }),
  source: SecretSource.fromConfig({
    keys: ["url", "password"],
    envName: (k) => `DB_${k.toUpperCase()}`
  })
})
// bound.manifest is the SealedSecret CR
```

For a whole bundle, pass the same backend to `Environment.bind({ env, namespace, secrets: { db: { backend, source } } })`.

## Surface

| Export | Purpose |
| --- | --- |
| `SealedSecrets.backend` | `(opts?)`: a `SecretBackend<N, K, true, SealedSecret>` |
| `SealedSecretsBackendOptions` | `scope?: "strict" \| "namespace-wide" \| "cluster-wide"` (default `strict`), `certPath?` (default `$KUBESEAL_CERT`) |
| `runKubeseal`, `resolveCertPath` | Low-level helpers: run `kubeseal` on a Secret, resolve the certificate path |
| `SealedSecret`, `SealedSecretSpec`, `SealedSecretTemplate`, `SealedSecretScope` | CR types |

## Errors

- `KubesealCertMissing`: neither `certPath` nor `KUBESEAL_CERT` is set.
- `KubesealInvocationError`: `kubeseal` exited non-zero or was not found.
- `KubesealParseError`: `kubeseal` output did not decode as a `SealedSecret`.

<Aside type="caution">
`scope` must match how the controller was asked to seal: `strict` binds to name and namespace, `namespace-wide` allows renaming inside the namespace, `cluster-wide` allows any namespace.
</Aside>

## Requirements

- `effect@4.0.0-rc.109` as an exact peer dependency (Effect 4, release candidate).
- Depends on `@konfig.ts/core`, `@konfig.ts/k8s`, and `yaml`.
- Runtime: Bun recommended; Node >= 23.6 works; Node 22.6 to 23.5 with `--experimental-strip-types`; `tsx` works.
